# lukeae2001.github.io

My personal site: [lukeae2001.github.io](https://lukeae2001.github.io)

One plain HTML file with inline CSS. No framework, no build step. `.github/workflows/pages.yml` publishes it to GitHub Pages on every push to `main`.

- `index.html`: the whole site
- `Luke-Edwards-CV.pdf`: the CV it links to
- `images/`: profile photo

The earlier Next.js version of the site is kept on the `old-nextjs-site` branch.
